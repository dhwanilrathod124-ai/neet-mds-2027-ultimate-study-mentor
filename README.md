# NEET-MDS 2027 Ultimate Study Mentor

An educational project designed to support BDS students and dental interns preparing for NEET-MDS.

## Project Goals
- Organize the complete NEET-MDS dental syllabus.
- Create structured revision notes and high-yield summaries.
- Develop original MCQs and verified previous-year question references.
- Build study planners, revision trackers, and Excel tools.
- Create PDF study resources and interactive learning tools.
- Support clinical learning with evidence-based dental education.
- Develop a website to make learning resources easier to access.

## Planned Features
1. Subject-wise study roadmap
2. Daily and weekly study planner
3. MCQ practice and performance tracking
4. Spaced-revision and error-log system
5. Dental classifications, mnemonics, and clinical correlations
6. Gujarat MDS counselling resources based on verified official information

## Accuracy and Sources
Previous-year questions, clinical facts, admission information, and references will be clearly labelled and verified where possible. Unverified information will not be presented as fact.

## Project Status
Early development. Features and resources will be added progressively.
